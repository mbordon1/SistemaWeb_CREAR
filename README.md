# CREAR - Sistema de Gestión Academia de Danzas

Sistema web administrativo para la academia de danzas CREAR.

## Tecnologías
- React 18 + Vite 5
- Tailwind CSS 3
- Supabase (base de datos + auth)
- React Router v6
- Lucide React (iconos)

## Instalación

```bash
npm install
cp .env.example .env
# Editá .env con tus credenciales de Supabase
npm run dev
```

## Módulos
- Dashboard
- Alumnos (CRUD)
- Grupos (CRUD)
- Profesores (CRUD)
- Inscripciones
- Asistencia
- Pagos y Cuotas
- Evaluaciones dinámicas
